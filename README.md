# OmorendaShop

Combined repository for the Omorenda Shopify storefront.

## Layout

- `Frontend/` — React + Vite storefront (TypeScript). See `Frontend/README.md`.
- `Backend/` — Node.js API with Prisma (TypeScript). See `Backend/README.md`.

## Getting started

Each app manages its own dependencies. Install and run from within its folder.

```bash
# Frontend
cd Frontend
cp .env.example .env
npm install
npm run dev

# Backend
cd Backend
cp .env.example .env
npm install
npm run dev
```
